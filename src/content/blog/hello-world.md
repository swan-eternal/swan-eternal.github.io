This is a blank post, ready to be replaced. The frontmatter above sets the
title, the one-line description that shows up in the blog list, the date, and
any tags.

Replace the body with whatever you want to write. A few conventions to keep:

- **Paragraphs** are separated by a blank line.
- **Headings** use `##` for sections. The page title comes from frontmatter.
- **Links** are `[text](https://example.com)`.
- **Images** work too: `![alt text](/photos/placeholder-1.jpg)` for something
  in `public/`, or a relative path for something sitting next to the Markdown
  file.

One more thing worth knowing: this site treats the Markdown body as the post.
Anything above the first heading is the intro, so keep it short.
